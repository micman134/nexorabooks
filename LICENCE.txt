A NOTE ON THIS FILE'S HISTORY
-----------------------------
This file replaced an MIT licence, which gave the software away to anybody who
received a copy. That MIT text used to be kept beside it as LICENSE-MIT-old.txt
and has now been removed, because shipping the two together risked giving the
software away by accident — which is exactly what nearly happened.

Removing the file does not by itself settle the question. If a copy of this
software was ever given to anybody while the MIT licence applied, that person
keeps MIT rights to the version they received, and no later relicensing takes
those rights back. If it was never distributed under MIT, there is nothing to
settle. Whoever sells this should know which of those is true.
