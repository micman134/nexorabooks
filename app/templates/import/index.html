If it goes wrong

Take a backup under Settings › Backup before you start. If an import brings in something you did not want, restoring that backup puts everything back exactly as it was — which is a great deal calmer than undoing four hundred rows by hand.

Opening balances are the exception: uploading a corrected trial balance simply replaces the previous one, so that file can be fixed and re-uploaded as often as you like.
